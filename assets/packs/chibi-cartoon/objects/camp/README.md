# objects / camp — Lakeside Camp

## Do not draw these yet

The evidence items are **text only**. They are printed as a list at the
foot of the puzzle page ("axe handle · bottle of pesticide · cast-iron
skillet") and named in evidence clues. **The engine draws no artwork for
them anywhere**, so a PNG placed here today is never rendered.

There are deliberately no per-item folders for that reason — folders would
invite art against a layout nobody has designed.

Art here becomes real when the two-page dossier spread exists (Phase 3,
`docs/roadmap.md`), which is the first layout with room to print an
evidence item large enough to be worth drawing. The folder stays so the
place is reserved and obvious.

Want to draw something for this theme now? Go to `../../furniture/camp/`
— those are drawn on every page.
