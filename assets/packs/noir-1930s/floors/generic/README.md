# Floors: generic

The fallback. A room whose name matches no band above lands here, so
these have to be neutral enough for any room: parquet, square tile, woven
matting, concrete, plank, cut stone.

This folder is the safety net, not a dumping ground — a floor that clearly
belongs to one kind of room belongs in that room's folder instead.

**4 minimum.** Name them `generic-01.png`, ...
