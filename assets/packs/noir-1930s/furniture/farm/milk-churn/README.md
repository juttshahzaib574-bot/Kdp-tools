# milk churn

**Put PNGs of a milk churn in this folder.** Nothing else goes here.

```
milk-churn-01.png
milk-churn-02.png
```

**2 minimum, 4 target.** Six props land on a page and a book runs thirty
pages, so one drawing means the same milk churn thirty times.

| | |
|---|---|
| Prints at | **0.22in - 0.5in** — the tightest brief in the pack |
| Draw at | 512 x 512 px minimum, PNG with transparency |
| Reads as | one silhouette. At half an inch, that is all there is |
| Colour | must survive grayscale — KDP black-ink interiors |
| Cell state | **blocked**. Never draw this as something to stand on |

The engine draws this procedurally today as its `globe` glyph. Your
artwork replaces that, so it has to carry the same read at the same size —
if a reader cannot tell it from the other five props on the page at half an
inch, it is too detailed, not too plain.
